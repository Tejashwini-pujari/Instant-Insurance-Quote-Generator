# 🤖 AI-Powered Instant Insurance Quote Generator with Risk Assessment & LLM Explanation

## 🚀 Features
- 🔍 Risk classification (Low / Medium / High)
- 💰 Automated insurance premium calculation
- 🧠 LLM-style human-readable explanation
- 📊 Graphical visualization of risk and premium
- ⚡ Fast and unbiased AI-based decision-making
- ☁️ Fully compatible with Google Colab

---

## 🧠 Technologies Used
- Python  
- Pandas, NumPy  
- Scikit-learn  
- Matplotlib  
- Machine Learning (Classification)  
- LLM-style Prompt Engineering

## 🔄 Workflow
1. Load historical insurance data  
2. Preprocess and encode features  
3. Train ML model for risk prediction  
4. Predict customer risk level  
5. Calculate premium using risk multipliers  
6. Generate LLM-style explanation  
7. Visualize results using graphs  

---

## 📊 Visualizations
- Risk probability bar chart  
- Premium comparison graph  
- Customer risk category visualization  

These graphs help users clearly understand **why a premium was assigned**.

---

## 🧠 LLM Explanation
Instead of showing only numbers, the system generates a **natural language explanation** describing:
- Customer profile  
- Risk category  
- Factors affecting premium  
- Final insurance cost  

Example:
> “Based on your accident history and coverage type, the AI model classified your profile as Medium Risk and calculated a premium accordingly.”
